# PROJECT.md

# AI Training Studio

Version: 1.0

---

# Project Vision

AI Training Studio is a professional desktop application built with Electron to help trainers, instructional designers, and organizations create high-quality educational content with Artificial Intelligence.

The application must remain stable, modular, and easy to extend.

---

# Main Objectives

The software allows users to create:

- Training courses
- Books
- Learning modules
- SCORM packages
- Quizzes
- AI-generated illustrations
- Professional PDF and DOCX exports

Everything is organized around projects.

---

# Target Users

- Corporate training centers
- Security companies
- Healthcare organizations
- Independent trainers
- HR departments
- Educational institutions

---

# Core Features

## Project Management

- Create projects
- Open projects
- Rename projects
- Delete projects
- Automatic save

---

## Workspace

The Workspace is the central screen.

It contains:

- Chapter explorer
- Rich text editor
- AI assistant
- Ribbon
- Status bar

---

## Rich Editor

The editor is based on Tiptap.

Features include:

- Rich text formatting
- Tables
- Images
- Lists
- Callouts
- Educational layouts

---

## AI Assistant

The AI assists users by generating:

- Course content
- Summaries
- Learning objectives
- Quizzes
- Illustrations
- Corrections
- Translations

---

## Export System

Supported formats:

- PDF
- DOCX
- HTML
- SCORM 1.2
- SCORM 2004

Future versions may support EPUB.

---

The application must feel modern and professional.

# Design Principles

The interface should be:

- Simple
- Fast
- Elegant
- Responsive
- Dark mode by default

---

# Technical Goals

- Modular architecture
- Clean code
- Stable releases
- Minimal regressions
- High performance
- ESLint, Prettier, and GitHub Actions CI quality checks

---

# Long-Term Vision

AI Training Studio should become a complete authoring platform capable of producing an entire professional training course—from planning to SCORM export—within a single application.
